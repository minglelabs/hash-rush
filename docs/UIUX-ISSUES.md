2026-10-31 기준 · 원본: [Claude 문서](https://claude.ai/artifact/PpKRG4G4USkwYroA5jDnoX)

## 개요

2026-10-10 첫 커밋부터 10-22(#229)까지 Hash Rush에서 나온 UI/UX 이슈를 영역별로 모았습니다. 대부분 모바일에서 나왔습니다. 조작, 채팅·키보드, 버튼 가림이 가장 많이 반복됐습니다.

- **출처**: hash-rush Claude 세션 7개(첫 개발, 조이스틱 조작감, 팀전 모드, 초고수 봇, 원격 렉, 목록보기 소리, 이 세션)의 사용자 요청, 그리고 main의 PR #1~#229 제목입니다. 봇 실력·RL 학습·맵 밸런스 같은 게임플레이 이슈는 화면이나 조작과 닿는 것만 넣었습니다.
- **출처 칸**: 요청 = 사용자가 직접 말한 것, 유저 피드백 = 사용자가 전달한 플레이어 후기, 발견 = Claude가 작업 중 찾은 것.
- **상태 칸**:
    - 해결 = 머지 후 사용자가 실기기에서 확인했다고 말한 것
    - 머지 = 코드는 들어갔지만 실기기 확인 여부가 기록에 없는 것
    - 부분 = 일부만 해결
    - 불가 = 웹페이지로는 막혀 있는 것
    - 열림 = 아직 손대지 않은 것 · 미검증 = 실기기 확인이 남은 것 · 대체됨 = 다음 방식으로 바뀐 것 · 철회 = 넣었다가 요청으로 뺀 것
- 같은 이슈가 여러 번 다시 나온 경우는 한 줄에 PR을 이어 적었습니다. 맨 뒤 PR이 마지막 조치입니다.
